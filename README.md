One line, at most 200 characters: the funniest excuse a robot vacuum could give.

> I wasn't late — the cat sat on me for an hour, and I've learned not to argue with management.

`main.ts` writes that line to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`) and reads it back to verify it matches exactly.
